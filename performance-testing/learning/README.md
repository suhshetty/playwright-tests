# Learning material

`k6-learning/` holds a 4-week k6 course worked through while building this framework:
small runnable exercises (`day1-smoke.js` … `day8b-sequential.js`) and the matching
notes in `k6-learning/notes/` (Word documents plus their HTML sources, a quick-reference
card and concept-map diagrams).

Most exercises hit public test sites, not MainManager. Run any of them with
`k6 run k6-learning/<file>.js`.

For a MainManager-specific walkthrough, start with
[../kommune/kt/scenario1-kt.html](../kommune/kt/scenario1-kt.html).
