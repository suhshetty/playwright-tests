Gap coverage from the Udemy course review

The Udemy k6 course (44 lessons, ~7 h) covers the tool well but omits the following. Each gap is deliberately covered on a specific day here — use this as a cross-check.

Recommended course usage: skip/skim sections 1–3 (covered here in more depth), watch sections 4–5 for scripting reps, watch sections 6–7 properly (k6 browser + Web Vitals — genuinely additive, not covered in this syllabus), and watch sections 8–9 (Grafana Cloud, Jenkins CI).

Explicitly out of scope

Server-side root-cause analysis is not in this syllabus (~40 h of separate study):

  • SQL Server diagnostics — execution plans, wait stats, blocking chains, index tuning
  • IIS / ASP.NET performance counters — request queue, thread pool, GC
Consequence to accept: after these 28 days you will be able to say “I can show you WHERE it is slow, not WHY.” Root-causing the ~22 s login and the load-triggered IsShortcut 500s needs the server-side skills above.

The five things to know cold

1.  throughput = VUs / iteration_duration        (rearrange for sizing)
2.  Report p95, never avg
3.  duration ~ waiting?   -> the server's fault, not yours
4.  avg > med?            -> a tail exists
5.  Checks AND thresholds, or the report is decoration
