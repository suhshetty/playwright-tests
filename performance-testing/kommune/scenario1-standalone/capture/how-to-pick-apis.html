⚠  Stuck on one? Use this test

Imagine deleting it. Does the next request still work?

If no → KEEP, however pointless it looks.

Three calls to saveToggleValue return 8 bytes of {"d":null}. Every instinct says drop them. But they tell the server which screen is open — without them the next call returns an empty page and the filters quietly stop working.

Small does not mean unimportant.

💡  Two settings first

Preserve log — or the list is wiped the moment the page navigates, and you lose the login requests.

Ctrl+click the Doc and Fetch/XHR buttons to select both. Fetch/XHR alone hides the .aspx pages.

✓  How you know you got it right

Not from the list — from the numbers. Run the script and compare against what the browser shows you.

[VERIFY] widgets=18
[VERIFY] recordsTotal=469

The dashboard has 18 tiles. The widget reads 469. The script sees 18 and 469.

Drop something that mattered and these come back empty or wrong. That is the real check.
